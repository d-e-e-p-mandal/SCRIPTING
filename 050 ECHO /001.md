# echo Command

## What is echo?

`echo` is used to print text or values to the terminal.

---

## Print Text

```bash
echo "Hello World"
```

Output:

```text
Hello World
```

---

## Print Variable

```bash
echo $HOME
```

Output:

```text
/Users/deepmandal
```

---

# Write to File

## Create File and Write

```bash
echo "Hello World" > file.txt
```

Creates `file.txt` and writes:

```text
Hello World
```

---

## Overwrite File

```bash
echo "New Data" > file.txt
```

Old content is removed.

New content:

```text
New Data
```

---

## Append to File

```bash
echo "Line 1" >> file.txt
echo "Line 2" >> file.txt
```

Content:

```text
Line 1
Line 2
```

---

# Difference

## >

Write / Overwrite

```bash
echo "Hello" > file.txt
```

Result:

```text
Hello
```

---

## >>

Append

```bash
echo "World" >> file.txt
```

Result:

```text
Hello
World
```

---

# Example

```bash
echo "Start" > log.txt
echo "Build Success" >> log.txt
echo "Program End" >> log.txt
```

`log.txt`

```text
Start
Build Success
Program End
```

---

# Memory Trick

```text
>   = Replace old content

>>  = Add to existing content
```
